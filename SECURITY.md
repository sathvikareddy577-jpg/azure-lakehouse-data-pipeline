# Security policy

This is a synthetic portfolio project. Do not submit real customer data,
credentials, access tokens, storage keys, Terraform state, or private endpoint
details in an issue or pull request.

If you discover a security problem, contact the repository owner privately
rather than publishing exploit details. Rotate any credential immediately if it
was committed, even if the commit is later removed.

The Azure templates use managed identities and RBAC. A development deployment
still requires a network-security review before it is adapted for production.
